# Accessibility

pzh-charts targets **WCAG 2.2 level AA**. This file is the accessibility reference for the chart library: the automated evidence, the implementation per criterion, the known deviations and guidance for consumers. It is an engineering record, not a certification of the library or of any deployment that uses it.

The automated tests use the axe-core version pinned in the root lockfile and run in jsdom. They cannot check rendered colour contrast, screen-reader output or legal compliance; those need the manual checks listed below.

## Automated evidence and manual checks

- **Automated, in CI** (`npm run check` runs the suite): [a11y.test.tsx](a11y.test.tsx) runs axe-core against every chart type in all three views (visueel / tabel / samengevat), in high contrast and while loading; no violation is tolerated. jsdom disables axe's colour-contrast rule, so [tokens.test.ts](tokens.test.ts) asserts the colour contracts instead: default text and muted text ≥4.5:1 on white; high-contrast text ≥7:1 and grid ≥3:1; the brand bar colour ≥3:1; a monotonically darkening sequential ramp; that high contrast changes no mark colour and adds no outline stroke; and that the pattern line reaches ≥3:1 against every default mark colour (series, sequential, status, bar and highlight). Custom palette colours are not asserted; at runtime the pattern line is whichever of white or black contrasts more with the fill.
- **Manual, before a release**: a keyboard-only walk of one card per type, a live axe scan of the sandbox at `/beta/charts`, reflow at 320 px, 200 % zoom, and a rendered-contrast check of legend text next to its swatch.

Run the automated part with:

```bash
npx vitest run src/pzh-charts
```

## Implementation notes by criterion

| WCAG 2.2 criterion                         | Implementation evidence                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1.1.1 Non-text content                     | Every chart SVG is a named `role='group'`; every data point is a focusable group whose `aria-label` carries the full readout ("Rotterdam — Nieuw: 100, Refurbished: 38").                                                                                                                                                                                                |
| 1.3.1 Info and relationships               | The tabel view is a real `<table>` with `caption`, `scope='col'/'row'` headers and a named category column; highlights get visually-hidden text, never color alone.                                                                                                                                                                                                      |
| 1.3.2 Meaningful sequence                  | Data groups follow category order; the table mirrors it.                                                                                                                                                                                                                                                                                                                 |
| 1.4.1 Use of color                         | Highlights carry hidden text labels; threshold classes carry a legend and hidden class names; the tabel view restates everything without color. High contrast adds line patterns per series.                                                                                                                                                                             |
| 1.4.3 Text contrast                        | Text `#16113B` (17.8:1) and muted text `#5C5C5C` (6.7:1) on white; both asserted ≥4.5:1 in tokens.test.ts.                                                                                                                                                                                                                                                               |
| 1.4.4 Resize text / 1.4.10 Reflow          | Charts measure their container (ResizeObserver) and reflow without horizontal scroll down to 320 px; UI text is rem-based. SVG data labels are px-sized but scale with browser zoom.                                                                                                                                                                                     |
| 1.4.11 Non-text contrast                   | Focus indicators and header controls use `--pzh-focus` / `--pzh-control` (`#281F6B`, 14:1 on white). High-contrast pattern lines are white or black, chosen per fill by computed contrast; tokens.test.ts asserts ≥3:1 for every default mark colour. _See deviation 1 for default-mode marks._                                                                          |
| 1.4.12 Text spacing                        | Table, legend and summary text tolerates spacing overrides; no clipping containers around body text.                                                                                                                                                                                                                                                                     |
| 1.4.13 Content on hover or focus           | Tooltips appear on hover **and** focus, dismiss with Escape, and repeat (never exceed in substance) the focused group's `aria-label`. They are hoverable: marks only set the active tooltip, the chart area clears it on leave, and the tooltip receives the pointer, so moving onto it does not dismiss or switch it.                                                   |
| 2.1.1 / 2.1.2 Keyboard                     | Every data point, the contrast toggle, the view select and scrollable tables are tab-reachable; nothing traps focus.                                                                                                                                                                                                                                                     |
| 2.3.3 Animation from interactions          | Every animation and transition — entry growth, tooltip entrance and glide, hover dim, toggle knob — sits behind `prefers-reduced-motion: no-preference`.                                                                                                                                                                                                                 |
| 2.4.3 Focus order                          | DOM order = visual order: header controls, then data groups in category order, then legend.                                                                                                                                                                                                                                                                              |
| 2.4.7 / 2.4.11 Focus visible, not obscured | `:focus-visible` outlines on controls and table regions; a 2 px `--pzh-focus` stroke on the focused mark (bars, slices, ring segments, bubbles, radar wedges). Tooltips are positioned above marks and never cover the focused element's indicator.                                                                                                                      |
| 2.5.7 Dragging                             | No drag interactions.                                                                                                                                                                                                                                                                                                                                                    |
| 2.5.8 Target size                          | Header controls are 40 px tall; data-point hit areas span the full column/row/slice. Very high category counts shrink per-column targets, and concentric rings thinner than 24 px do the same — a ring's hit area covers its whole circle including the gaps, and past five rings the chart falls back to one stacked ring. The tabel view is the equivalent affordance. |
| 3.1.1 / 3.1.2 Language                     | The card root sets `lang` (default `nl`, follows the `labels` prop), so Dutch chart copy is announced correctly on any host page.                                                                                                                                                                                                                                        |
| 3.2.1 / 3.2.2 On focus / on input          | Focus and input never change context; the view select swaps content in place and announces it via a status region.                                                                                                                                                                                                                                                       |
| 3.3.1 / 3.3.2 Errors, labels               | The library has no free-text inputs and no error states. Its two controls are the visibly labelled view `<select>` ("Weergave") and the contrast toggle button with its text label.                                                                                                                                                                                      |
| 4.1.2 Name, role, value                    | Native controls (`button` with `aria-pressed`, `select`); data groups are `role='img'` with names; chart SVGs `role='group'`; axe reports no prohibited ARIA.                                                                                                                                                                                                            |
| 4.1.3 Status messages                      | Skeletons expose a visually hidden `role='status'` region ("Aan het laden…"); view switches announce the new view through a status region.                                                                                                                                                                                                                               |

## Known deviations

1. **Default-mode mark colors below 3:1** — Yellow 500 `#EFCC36` (1.6:1) and Orange 500 `#FF6B02` (2.9:1) against white do not meet 1.4.11 as bare fills. These are fixed brand colors. Mitigations: the **tabel view** presents the same data conformantly on every card; **high contrast** keeps the colors and overlays ≥3:1 line patterns; adjacent marks are separated by gaps and never rely on hue alone (legend + readouts).
2. **SVG data labels are px-sized** (12–13 px axis/tick text). They scale with page zoom (1.4.4's supported mechanism) but not with text-only zoom. The tabel view provides the same values in rem-sized text.

## Recorded PZH audit follow-up

Commit `d3c87e0` records follow-up on findings attributed to WCAG Radar developer, designer and editor reports. The original reports are not in the repository; the table preserves the developer explanations.

| Recorded finding                                            | Implementation / developer explanation                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Chart titles were `<p>` — no heading structure              | Card titles are real headings; `headingLevel` prop (default `h2`) lets the card slot into the page outline.                                                                                                                                                                                                                                                                                                                    |
| Tabs' `aria-controls` referenced panel ids that don't exist | Panels render lazily, so only the selected tab carries `aria-controls`; verified by test.                                                                                                                                                                                                                                                                                                                                      |
| Legend labels measured at 1.27:1–3.56:1 contrast            | Developer explanation, requiring rendered contrast verification: the text (`#16113B`, 17.8:1 on white) was measured against the adjacent colour dot, an inline `<span>` with a CSS background. The dot is now an inline SVG (`Swatch`) with no CSS background, so checkers measure text on its real background; in high contrast the dot also shows the mark's pattern.                                                        |
| Skeleton pulse animates indefinitely (2.2.2)                | Pulse runs 3 cycles (4.8 s) and rests as a static skeleton; still behind `prefers-reduced-motion`.                                                                                                                                                                                                                                                                                                                             |
| View select had no visible label                            | Visible "Weergave" `<label>` bound to the select.                                                                                                                                                                                                                                                                                                                                                                              |
| Demo copy referred to position ("van links naar rechts")    | Sandbox copy reworded; the library itself never references position, colour or shape.                                                                                                                                                                                                                                                                                                                                          |
| "Aan het laden…" flagged as an unlinked error message       | Developer explanation, requiring review against the original report: it is the skeleton's `role='status'` region (4.1.3), not a form error — kept as is.                                                                                                                                                                                                                                                                       |
| `aria-hidden` warnings                                      | `aria-hidden='true'` is set only on decorative or duplicate graphics: the legend, table and tooltip swatches (`Swatch`), the toggle track, the zero-size pattern-definition SVG, the skeleton placeholders (their status text stays exposed) and the transient crosshair and active-point markers in the line and radar charts. Their meaning is carried by adjacent text, `aria-pressed` or the focused group's `aria-label`. |

## For consumers

- Set `headingLevel` to match your page outline (default `2`); the title is a real heading.
- Provide a `title` — it names the card (`aria-labelledby`) and the table caption.
- Pass `axis.xLabel` where meaningful; it becomes the table's category header.
- If you override `labels`, keep `lang` in sync with the language of your strings.
- Don't encode meaning in color alone; use `highlight`/`note`/thresholds, which all carry text equivalents.
