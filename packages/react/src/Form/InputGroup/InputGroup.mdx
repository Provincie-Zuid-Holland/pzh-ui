# InputGroup

Een component voor invoervelden met aanvullende content vóór, na, boven of onder de invoer.

Gebruik `InputGroup` wanneer een input gecombineerd moet worden met bijvoorbeeld een eenheid, icoon, prefix, suffix of actieknop.

## Gebruik

```tsx
import {
    InputGroup,
    InputGroupAddon,
    InputGroupInput,
    InputGroupText,
} from '@pzh-ui/react'

export function Example() {
    return (
        <InputGroup>
            <InputGroupAddon align="inline-start">
                <InputGroupText>€</InputGroupText>
            </InputGroupAddon>

            <InputGroupInput aria-label="Bedrag" placeholder="0,00" />
        </InputGroup>
    )
}
```

## Disabled

De disabled state wordt bepaald door het invoerveld.

<Canvas of={InputGroupStories.Disabled} />

```tsx
<InputGroup>
    <InputGroupAddon align="inline-start">
        <InputGroupText>€</InputGroupText>
    </InputGroupAddon>

    <InputGroupInput aria-label="Bedrag" defaultValue="123,45" disabled />
</InputGroup>
```

Wanneer het invoerveld disabled is, krijgt de volledige groep automatisch de disabled styling.

## Formaten

`InputGroup` ondersteunt dezelfde formaten als `Input`.

Beschikbare formaten:

- `l`
- `m`

```tsx
<InputGroup size="l">
    <InputGroupInput aria-label="Large input" />
</InputGroup>

<InputGroup size="m">
    <InputGroupInput aria-label="Medium input" />
</InputGroup>
```

## Opbouw

Het component bestaat uit vijf onderdelen.

### `InputGroup`

De container van de complete invoer. Deze verzorgt de border, achtergrond, focus state en validatie.

### `InputGroupInput`

Het daadwerkelijke invoerveld.

De focus van dit element wordt automatisch weergegeven op de volledige `InputGroup`.

### `InputGroupAddon`

Container voor aanvullende content.

Ondersteunde posities:

- `inline-start`
- `inline-end`
- `block-start`
- `block-end`

### `InputGroupText`

Gebruik voor tekstuele aanvullingen zoals:

- valuta
- eenheden
- prefixes
- suffixes

### `InputGroupButton`

Een knop die onderdeel is van de inputgroep.

## Toegankelijkheid

Gebruik altijd een zichtbaar label.

```tsx
<Field>
    <FieldLabel htmlFor="amount">Bedrag</FieldLabel>

    <InputGroup>
        <InputGroupAddon align="inline-start">
            <InputGroupText>€</InputGroupText>
        </InputGroupAddon>

        <InputGroupInput id="amount" name="amount" />
    </InputGroup>
</Field>
```

Voor icon-only knoppen is een toegankelijk label verplicht.

```tsx
<InputGroupButton aria-label="Zoeken">
    <MagnifyingGlass />
</InputGroupButton>
```

Voor foutmeldingen combineer je `aria-invalid` met `aria-describedby`.

```tsx
<InputGroup>
    <InputGroupInput
        id="amount"
        aria-invalid
        aria-describedby="amount-error"
    />
</InputGroup>

<FieldError id="amount-error">
    Vul een geldig bedrag in.
</FieldError>
```

### Richtlijnen

- Gebruik `InputGroup` alleen wanneer aanvullende content direct bij de invoer hoort.
- Gebruik `InputGroupText` voor korte prefixes, suffixes en eenheden.
- Gebruik `InputGroupButton` voor acties die direct betrekking hebben op de invoer.
- Geef icon-only knoppen altijd een `aria-label`.
- Gebruik `inline-start` en `inline-end` voor content naast de input.
- Gebruik `block-start` en `block-end` voor content boven of onder de input.
- Gebruik `aria-invalid` samen met een duidelijke foutmelding.
- Gebruik altijd een zichtbaar label.
