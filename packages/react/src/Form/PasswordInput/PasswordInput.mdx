# PasswordInput

Een component voor het invoeren van wachtwoorden met een optionele knop om het wachtwoord tijdelijk zichtbaar te maken en een optionele indicatie van de wachtwoordsterkte.

Het component is opgebouwd met `InputGroup` en gebruikt standaard een password input.

## Gebruik

```tsx
import { PasswordInput } from '@pzh-ui/react'

export function Example() {
    return (
        <PasswordInput name="password" placeholder="Voer een wachtwoord in" />
    )
}
```

## Wachtwoord tonen en verbergen

Wanneer het veld een waarde bevat, wordt standaard een knop getoond waarmee de gebruiker het wachtwoord zichtbaar of verborgen kan maken.

<Canvas of={PasswordInputStories.WithValue} />

```tsx
<PasswordInput defaultValue="SuperSecret123!" />
```

De knop wordt alleen weergegeven wanneer:

- `showToggle` niet `false` is;
- het veld een waarde bevat;
- het veld niet disabled is.

De knop krijgt automatisch een toegankelijk label:

- `Wachtwoord tonen`
- `Wachtwoord verbergen`

## Zonder toggle

Gebruik `showToggle={false}` wanneer het wachtwoord niet zichtbaar gemaakt mag worden.

<Canvas of={PasswordInputStories.WithoutToggle} />

```tsx
<PasswordInput defaultValue="SuperSecret123!" showToggle={false} />
```

De `showToggle`-property staat standaard op `true`.

## Wachtwoordsterkte

Gebruik `showStrength` om onder het invoerveld een indicatie van de wachtwoordsterkte te tonen.

<Canvas of={PasswordInputStories.WithStrength} />

```tsx
<PasswordInput showStrength />
```

De sterkte-indicator wordt alleen weergegeven wanneer:

- `showStrength` `true` is;
- het veld een waarde bevat.

Standaard worden drie niveaus gebruikt:

- `weak` – Zwak
- `medium` – Niet zo goed
- `strong` – Sterk

De indicator bestaat uit een voortgangsbalk en een tekstuele aanduiding.

### Voorbeeld

#### Sterk

<Canvas of={PasswordInputStories.StrongStrength} />

```tsx
<PasswordInput defaultValue="SuperSecret123!" showStrength />
```

## Eigen sterkteberekening

Met `getStrength` kan de standaardberekening worden vervangen door applicatiespecifieke wachtwoordregels.

De functie ontvangt de actuele waarde en moet `weak`, `medium` of `strong` teruggeven.

```tsx
<PasswordInput
    showStrength
    getStrength={value => {
        if (value.length >= 16) {
            return 'strong'
        }

        if (value.length >= 8) {
            return 'medium'
        }

        return 'weak'
    }}
/>
```

Gebruik een eigen `getStrength` wanneer de applicatie specifieke eisen stelt aan wachtwoorden.

## Controlled en uncontrolled

`PasswordInput` ondersteunt zowel controlled als uncontrolled gebruik.

### Uncontrolled

Gebruik `defaultValue` wanneer het component zelf de waarde beheert.

```tsx
<PasswordInput defaultValue="SuperSecret123!" />
```

### Controlled

Gebruik `value` in combinatie met `onChange` wanneer de waarde buiten het component wordt beheerd.

```tsx
import { useState } from 'react'
import { PasswordInput } from '@pzh-ui/react'

export function Example() {
    const [password, setPassword] = useState('')

    return (
        <PasswordInput
            value={password}
            onChange={event => setPassword(event.target.value)}
        />
    )
}
```

De visibility toggle en sterkte-indicator blijven in beide situaties gebaseerd op de actuele waarde van het veld.

## Disabled

Gebruik `disabled` wanneer het wachtwoordveld niet beschikbaar is.

<Canvas of={PasswordInputStories.Disabled} />

```tsx
<PasswordInput defaultValue="SuperSecret123!" disabled />
```

Bij een disabled veld wordt de knop voor tonen en verbergen niet weergegeven.

## Read only

Gebruik `readOnly` wanneer de waarde zichtbaar en selecteerbaar moet blijven, maar niet gewijzigd mag worden.

<Canvas of={PasswordInputStories.ReadOnly} />

```tsx
<PasswordInput defaultValue="SuperSecret123!" readOnly />
```

## Validatie

Gebruik `aria-invalid` om een foutstatus weer te geven.

<Canvas of={PasswordInputStories.Invalid} />

```tsx
<PasswordInput
    defaultValue="SuperSecret123!"
    aria-invalid
    aria-describedby="password-error"
/>

<FieldError id="password-error">
    Het wachtwoord voldoet niet aan de eisen.
</FieldError>
```

De sterkte-indicator is uitsluitend informatief en vervangt geen validatie.

## Gebruik binnen Field

Combineer `PasswordInput` met `Field` voor een volledig formulierveld.

```tsx
import {
    Field,
    FieldDescription,
    FieldError,
    FieldLabel,
    PasswordInput,
} from '@pzh-ui/react'

export function Example() {
    return (
        <Field className="flex-col">
            <FieldLabel htmlFor="password" required>
                Wachtwoord
            </FieldLabel>

            <FieldDescription>
                Gebruik minimaal acht tekens.
            </FieldDescription>

            <PasswordInput
                id="password"
                name="password"
                autoComplete="current-password"
                required
            />
        </Field>
    )
}
```

Voor een nieuw wachtwoord is het gebruik van de sterkte-indicator aan te raden:

```tsx
<Field className="flex-col">
    <FieldLabel htmlFor="new-password" required>
        Nieuw wachtwoord
    </FieldLabel>

    <FieldDescription>
        Gebruik minimaal acht tekens.
    </FieldDescription>

    <PasswordInput
        id="new-password"
        name="newPassword"
        autoComplete="new-password"
        showStrength
        required
    />
</Field>
```

## Nieuw wachtwoord

Gebruik bij het aanmaken van een nieuw wachtwoord bij voorkeur `autoComplete="new-password"`.

```tsx
<PasswordInput
    name="newPassword"
    autoComplete="new-password"
    showStrength
/>
```

Voor een bestaand wachtwoord gebruik je:

```tsx
<PasswordInput
    name="password"
    autoComplete="current-password"
/>
```

De sterkte-indicator is vooral bedoeld voor het kiezen of wijzigen van een wachtwoord.

## Opbouw

`PasswordInput` bestaat uit:

- `InputGroup` als visuele container;
- `InputGroupInput` voor het daadwerkelijke wachtwoordveld;
- een optionele `InputGroupAddon`;
- een `InputGroupButton` voor het tonen en verbergen van het wachtwoord;
- een optionele sterkte-indicator.

Standaard wordt het invoerveld gerenderd als:

```tsx
type = 'password'
```

Wanneer de gebruiker het wachtwoord zichtbaar maakt, verandert het tijdelijk naar:

```tsx
type = 'text'
```

De daadwerkelijke waarde verandert hierbij niet.

## Toegankelijkheid

Gebruik altijd een zichtbaar label.

```tsx
<Field>
    <FieldLabel htmlFor="password">Wachtwoord</FieldLabel>

    <PasswordInput id="password" name="password" />
</Field>
```

De visibility toggle heeft automatisch een beschrijvend `aria-label`, waardoor duidelijk is welke actie wordt uitgevoerd.

De sterkte-indicator gebruikt naast kleur ook een tekstuele omschrijving, zodat de informatie niet uitsluitend afhankelijk is van kleur.

Gebruik voor validatiefouten `aria-invalid` en verbind de foutmelding via `aria-describedby`.

```tsx
<Field>
    <FieldLabel htmlFor="password">Wachtwoord</FieldLabel>

    <PasswordInput
        id="password"
        name="password"
        aria-invalid
        aria-describedby="password-error"
    />

    <FieldError id="password-error">
        Het wachtwoord voldoet niet aan de eisen.
    </FieldError>
</Field>
```

### Richtlijnen

- Gebruik `PasswordInput` voor wachtwoorden in plaats van een reguliere `Input`.
- Laat de visibility toggle standaard ingeschakeld.
- Gebruik `showToggle={false}` alleen wanneer het wachtwoord niet zichtbaar gemaakt mag worden.
- Gebruik `showStrength` bij voorkeur voor nieuwe of gewijzigde wachtwoorden.
- Gebruik `autoComplete="current-password"` voor bestaande wachtwoorden.
- Gebruik `autoComplete="new-password"` voor nieuwe wachtwoorden.
- Gebruik `disabled` alleen wanneer interactie volledig onmogelijk moet zijn.
- Gebruik `readOnly` wanneer de waarde zichtbaar maar niet wijzigbaar moet zijn.
- Gebruik `aria-invalid` samen met een duidelijke foutmelding.
- Gebruik altijd een zichtbaar label.
- Kies `size="l"` als standaardformaat.
- Gebruik `size="m"` voor compactere formulieren.
