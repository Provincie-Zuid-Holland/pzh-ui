# Tooltip

Een tooltip toont korte aanvullende informatie wanneer een gebruiker met de muis over een element beweegt of het element met het toetsenbord focust.

## Gebruik

```tsx
import { Button, Tooltip, TooltipTrigger } from '@pzh-ui/react'

<TooltipTrigger>
    <Button>Meer informatie</Button>
    <Tooltip>Dit is aanvullende informatie.</Tooltip>
</TooltipTrigger>
```

## Plaatsing

Gebruik `placement` om de voorkeurspositie van de tooltip te bepalen. De tooltip kan automatisch van positie wisselen wanneer er onvoldoende ruimte beschikbaar is.

## Toegankelijkheid

- Gebruik een tooltip alleen voor aanvullende informatie.
- Plaats essentiële informatie ook zichtbaar in de interface.
- `TooltipTrigger` ondersteunt zowel hover als toetsenbordfocus.
- Plaats geen interactieve elementen in een tooltip.
